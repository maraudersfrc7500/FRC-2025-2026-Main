motorLF3 -> Left Follower Motor of ID 3

motorRL2 -> Right Lead Motor of ID 2

motorRF4 -> Right Follower Motor of ID 4

motorIF6 -> Intake Follower Motor of ID 6

## Omnispike Subsystem
motorSP7 -> Spike Motor of ID 7

## Launcher Subsystem
motorLL9 -> Launcher Lead Motor of ID 9

motorLF10 -> Launcher Follower Motor of ID 10

## Climb Subsystem
motorCL11 -> Climb Lead Motor of ID 11

motorCF12 -> Climb Follower Motor of ID 12
